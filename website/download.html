Get PSphere

Install PSphere on every device you want in your backups: your phone, your tablet and your Windows laptop. They link to each other once and back each other up from then on.

The first release of version 2.0 is being prepared. When it's published, the Android and Windows files will be on the releases page. Until then you can build PSphere from source.

Android

Install the APK

PSphere isn't on the Play Store yet, so you install it directly. It takes about two minutes, and you can uninstall it like any other app.

  1. Download the APK on your phone

    Open the releases page on the phone and download the newest .apk file. You can also copy it over from a computer with a USB cable.

  2. Allow your browser or file manager to install apps

    Open the APK. If Android asks, tap Settings and turn on Allow from this source. On most phones this is under Settings → Apps → Special app access → Install unknown apps.

  3. Install and open PSphere

    Tap Install. You can turn “Install unknown apps” off again afterwards.

  4. Name the device and link it

    Give the phone a name your other devices will see, like “Phone”. Then open Devices → Link a device to link it with your laptop or tablet.

Windows

Install on Windows

The installer puts PSphere in your Start menu. It needs no administrator rights and includes everything it needs to run.

  1. Download and open the installer

    Download the newest .msi file from the releases page and open it. The installer isn't code-signed yet, so Windows may say Windows protected your PC: choose More info, then Run anyway.

  2. Allow it on private networks

    The first time PSphere runs, Windows Firewall asks about it. Allow Private networks; that's what lets your phone find the laptop. Your home Wi-Fi should be set as a private network in Windows.

  3. Choose where backups go

    In Receiving, choose a folder or drive for backups from your other devices, such as D:\PSphere Backups.

  4. Link your phone

    Open Devices → Link a device. Scan the QR code with PSphere on your phone. Then, on the phone, choose folders to back up to the laptop in Sending.
