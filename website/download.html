Android

Install the APK

P-Sphere isn't on the Play Store yet, so you install it directly. It takes about two minutes and you can uninstall it like any other app.

  1. Download the APK on your phone

    Open the releases page on the phone and download the newest .apk file. You can also copy it over from a computer with a USB cable.

  2. Allow your browser or file manager to install apps

    Open the APK. If Android asks, tap Settings and turn on Allow from this source. On most phones this lives under Settings → Apps → Special app access → Install unknown apps.

  3. Install and open P-Sphere

    Tap Install. You can turn “Install unknown apps” off again afterwards.

  4. Allow access to photos

    P-Sphere asks to read your photos and videos. It needs this to back them up. Notifications are optional and only show sync progress.

  5. Choose “Start with nearby sync” and pick a folder

    In Settings → Backup, choose the folder to back up (usually DCIM/Camera). Do the same on your other phone, then tap Sync now.
