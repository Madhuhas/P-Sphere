Overview

P-Sphere is a self-hosted photo library. The goal is to give you everything a cloud photo service offers — backup, search, albums, AI — without your photos ever leaving devices you control.

Right now, the Android app is working. It backs up your camera roll and syncs photos between devices on your local Wi-Fi network with no server required. The rest of the platform is in active development.

What works today:

  • Automatic camera roll backup (to another device on your network)
  • P2P sync between Android phones on the same Wi-Fi
  • Hash-based delta sync (only new photos are transferred)
  • Background sync using Android WorkManager
P-Sphere is alpha software. It is not production-ready. Always maintain independent backups of your photos outside of P-Sphere.

Installing the app

P-Sphere is not on the Google Play Store yet. You install it by sideloading the APK file. This is safe and reversible.

Full step-by-step instructions are on the download page. In short:

  1. Download the APK from the releases page
  2. Enable "Install unknown apps" for your browser or file manager
  3. Tap the APK file and confirm installation
  4. Open P-Sphere and grant the required permissions

Permissions

P-Sphere requests two permissions:

  • Photos / Media access — Required. Needed to read your camera roll for backup and sync.
  • Notifications — Optional. Used to show sync progress and completion notices.

P-Sphere does not request location, contacts, microphone, or camera permissions. No data is sent to any external server.

Photo backup

When another P-Sphere device is available on your network (either a phone or, in the future, the core server), the app backs up your camera roll automatically in the background.

Backup behaviour:

  • Runs automatically on a configurable schedule (default: every 6 hours)
  • Only runs on Wi-Fi by default — you can optionally allow mobile data in settings
  • Skips backup when battery is low
  • Can be triggered manually from the app at any time

P2P sync

P2P mode lets two Android phones running P-Sphere sync photos directly over the same Wi-Fi network. No server or internet connection is needed.

How discovery works

P-Sphere uses Android's Network Service Discovery (NSD / mDNS) to broadcast its presence on the local network. Any other P-Sphere device on the same network will appear in the app's device list automatically. No IP addresses or pairing codes required.

How transfer works

Once you initiate a sync, P-Sphere:

  1. Exchanges a list of SHA-256 photo hashes with the other device
  2. Identifies which photos each device is missing
  3. Transfers only those files over a direct TCP connection

This means syncing is always incremental — transferring a library of 5,000 photos the first time is slow, but every sync after that takes seconds.

Security

Connections are local-network only and require explicit authorization on both devices the first time. P-Sphere does not expose any port to the internet.

Delta sync

Every photo is identified by its SHA-256 content hash, not its filename or date. This means:

  • Renaming or moving a photo doesn't cause it to re-upload
  • Duplicates are detected automatically and skipped
  • If a photo exists on the receiving device (even under a different name), it won't be transferred again

This makes repeated syncs very fast, even for large libraries.

Core server Coming soon

The core server is a self-hosted Node.js backend that will act as the permanent home for your photo library. Once available, it will:

  • Store photos on disk and serve them to connected devices
  • Run the AI pipeline (tagging, face detection, search) in the background
  • Serve the web dashboard
  • Manage device tokens and sync state

You'll be able to run it on any always-on machine: a spare PC, a Raspberry Pi, a NAS, or a small VPS.

Tech stack: Node.js 20, Express, PostgreSQL, Redis, BullMQ.

Web dashboard Coming soon

The web dashboard is a React app served by the core server. You'll be able to access it from any browser on your local network at http://<server-ip>:5173.

Planned features: photo timeline, album management, AI search, face cluster labelling, sync status.

AI features Coming soon

All AI in P-Sphere runs locally. Nothing is sent to an external API.

  • Natural language search — powered by a local LLM (Ollama, LM Studio, or any OpenAI-compatible endpoint you run yourself)
  • Smart albums — the LLM clusters your photos into Trip, People, Pets, and Place albums
  • Face detection and clustering — runs ONNX models offline, groups similar faces across your library
  • Object tagging — identifies objects and scenes in your photos for richer search

FAQ

Does P-Sphere work without the internet?

Yes. The Android app and P2P sync work entirely over your local Wi-Fi network. No internet connection is required for any currently available feature.

Do I need an account?

Not currently. The Android app works without any account or registration. When the core server is released, you'll create a local account on your own server — there's no central account system.

Is my data safe?

P-Sphere stores photos on the devices involved in the sync. Data safety depends on the health of those devices. We strongly recommend keeping independent backups — P-Sphere is alpha software and data loss is possible.

Can multiple people use P-Sphere on the same network?

Each phone runs its own independent instance. Multi-user support with shared libraries and per-user accounts is planned for the core server release.

Is the source code available?

P-Sphere is currently proprietary software. License terms are on the License page. We may release it under an open-source license as the project matures.

How do I report a bug?

Open an issue on the GitHub repository. Please include your Android version, the app version, and a description of what happened.

Privacy

P-Sphere is designed so your photos never leave your devices:

  • No external servers are involved in any currently available feature
  • The app collects no analytics or telemetry
  • No crash reports are sent automatically — you would need to do so manually
  • P2P sync happens directly between your devices over your local network
  • No account is needed, so there is nothing to track you with

When the core server is released, that server will also be self-hosted on hardware you own. We will never operate cloud infrastructure on your behalf or have access to your photos.
